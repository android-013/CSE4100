# CSE4100 Industrial Training

This repository contains the practical work and training materials for the CSE4100 Industrial Training course.

## Course Overview

The course focuses on developing practical web development and design skills using modern tools and best practices. Students are introduced to React JS front-end design techniques through hands-on projects.

## Project Structure

- `day-01-profile/` - HTML
- `index.html` - Main page or project entry point

## Objectives

- Learn the basics of web page structure
- Practice styling with CSS
- Build simple, clean, responsive UI layouts
- Understand how to organize project files and assets

## Tools Used

- HTML
- CSS
- Git and GitHub
- VS Code

## Notes

This repository is intended for learning and coursework completion during the industrial training program.
